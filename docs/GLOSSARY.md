# Glossary

- Product Group: root category for production data. Persian: گروه محصول.
- Production Line: manufacturing line. Persian: خط تولید.
- Product: produced item linked to a product group. Persian: محصول.
- Raw Material: material consumed in production. Persian: ماده اولیه.
- Waste Type: classified waste. Persian: نوع ضایعات.
- Reusable Waste: waste that can be reused. Persian: قابل مصرف مجدد.
- Saleable Waste: waste that can be sold. Persian: ضایعات فروشی.
- Shift: work shift. Persian: شیفت.
- Operator: responsible operator. Persian: اپراتور.
- Crew Count: number of staff in the shift. Persian: تعداد نفرات شیفت.
- Total Production: total reported output. Persian: تولید کل.
- Useful Production: useful/good output. Persian: تولید مفید.
- Yield: useful production divided by total production. Persian: راندمان.
- Silo Inventory: material remaining from earlier periods, reason for removing strict material balance checks.
